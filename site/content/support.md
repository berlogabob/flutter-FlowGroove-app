# Support

FlowGroove helps musicians and bands organize songs, setlists and practice tools
(metronome and tuner) in one place. Need a hand? We're happy to help.

## Contact

- **Email:** [hello@flowgroove.app](mailto:hello@flowgroove.app)

We usually reply within a couple of days.

## Troubleshooting

**Can't sign in / reset password**
Make sure you're using the same method (email or Google) you signed up with. For a
password reset, use *Forgot password* on the sign-in screen. Still stuck? Email us.

**Import / export (CSV)**
Songs import and export as CSV. If an import looks off, check that the column
headers match the exported template, then re-import.

**Microphone / tuner**
The tuner needs microphone permission. If it isn't listening, grant FlowGroove
microphone access in your device or browser settings. Audio is processed on your
device only and is never recorded or uploaded — see our [Privacy Policy](/privacy/).
