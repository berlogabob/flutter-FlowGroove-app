# UX-008 — микротекст транспортной панели тюнера

## CODE: независимо проверено Hermes

`TransportBar` читает `tunerProvider`, строит ряд высотой 80 с отступами; Generate показывает громкость, Listen — входной уровень (`lib/widgets/tuner/transport_bar.dart:23-44`). Центральная кнопка меняет Play/Mic на Stop; Listen создаётся только при неактивном режиме прослушивания (`:97-110`). Калибровка доступна в обоих режимах и открывает существующий settings sheet (`:67-74`).

Подпись `A4 <частота>` использует `labelSmall.copyWith(fontSize: 7)` внутри 56×56, `Positioned(bottom: 4)` (`:281-305`). У `Listen` нет локального fontSize: используется `labelSmall`, но текст расположен в Stack с `bottom: -18` (`:129-152`). Создание Text не доказывает его видимость за пределами Stack: clipping/реальный painted layout отдельно не проверены.

Актуальный `MonoPulseTypography.labelSmall` — **11**, не предположенные worker-ом 9 (`lib/theme/mono_pulse_theme.dart:450-454`). В этом TransportBar нет второго локального fontSize 9; исходная формулировка аудита историческая. Геометрические тесты (`test/widgets/tuner/central_dial_geometry_test.dart:6-98`) проверяют публичный TunerDialGeometry, не строят TransportBar и не доказывают читаемость.

## HYPOTHESIS и минимальный следующий шаг

Размер 7 — подтверждённое локальное уменьшение относительно токена, но не измеренное нарушение WCAG или доказанная проблема человека. Кандидат на минимальный change — убрать только fontSize 7, сохранив цвет, вес, калибровку, состояние и аудиомодель. Это даст 11, а не 9; достаточность размещения не установлена.

**UX-008-I пока blocked на rendered preflight:** проверить существующие публичные tuner fixtures/реальный layout и согласованный тестовый шов до теста/изменения production. Нельзя помещать UI regression в геометрический тест только потому, что он ошибочно назначен реестром. Нужны состояния Generate/Listen и реальные ограничения, normal/large text, отсутствие clipping/overflow калибровки; изменение положения Listen — отдельный срез, если будет подтверждено. No automatic font-size compliance threshold.

Тесты/устройство/контраст/человеческая читаемость не проверялись; исходники не менялись. UX-008 и release hold остаются открытыми. Это приёмка исследования, не исправление дефекта.
