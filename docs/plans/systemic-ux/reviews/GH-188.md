## Smallest coherent scope

Add per-area hidden/view/edit selection to the shared Add/Edit crew sheet, initialize selections from the current role preset for new people and from the person's stored access on edit, and render the preview from the effective selections. Persist those selections in the returned `EventPerson.access`; do not mutate presets. Define role-change behavior deliberately: current edit code resets access on role change, so preserve that behavior as a reset-to-new-preset (then allow overrides), unless product acceptance specifies retaining overrides. Keep canSuggest behavior independent and unchanged. This covers add, existing-person edit, live preview, persisted one-event escalation, and unchanged next-event preset without new model infrastructure.
