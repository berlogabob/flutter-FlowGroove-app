# Baseline: системный UX/UI аудит, 2026-10-23

Статус: 9 открытых findings; не исправления. Исходный полный локальный аудит в audit/2026-10-23-systemic-ux/ (gitignored, содержит приватные evidence). Реестр исполнения — activity.json, этот документ фиксирует исходную точку.

## UX-001 · S3 · Practice и фактическая практика разделены по разным понятиям

Practice показывает статистику, домашние задания и журнал; Quick start ведёт в Metronome/Tuner/Recorder. MIDI launchpad и непосредственное исполнение находятся в Metronome. Это подтверждённое распределение функций, а не результат наблюдения за растерянностью пользователя.

Критерий: H2 / H6 / IA-task. Evidence: DEVICE+CODE.

Направление: Сделать явным различие «заниматься» / «журнал». Один основной вход Practice должен вести к материалу и управлению занятием; существующий журнал сохранить как Progress/History, не переписывать аудиодвижок.

Код: `lib/screens/practice_screen.dart:14-17`, `lib/screens/practice_screen.dart:33-85`.

## UX-002 · S2 · Menu совмещает глобальную навигацию и контекстные команды

Пятый слот корневой панели выглядит как сосед вкладок, но открывает меняющееся меню. На Home доступны профиль/Settings, на Setlists — команды библиотеки. У дочернего объекта Menu опять означает его операции. Внутренний API намеренно реализует эти режимы; ошибку роутера этим не доказать.

Критерий: H4 / NAV-scope. Evidence: DEVICE+CODE.

Направление: Стабильный глобальный More с инструментами, профилем и настройками. Команды текущего списка/объекта — отдельное явно контекстное меню. Не менять состав остальных корневых вкладок без проверки задач.

Код: `lib/widgets/bottom_nav_or_action_bar.dart:10-16`, `lib/widgets/bottom_nav_or_action_bar.dart:96-105`, `lib/screens/main_shell.dart:180-266`.

## UX-003 · S2 · Открытие объекта непоследовательно: песня сразу Edit, сетлист — просмотр

Нажатие карточки песни открыло Edit с заполненной формой и командами редактирования; нажатие карточки сетлиста — read-only экран. Самопроизвольное сохранение или потеря данных не наблюдались и не проверялись.

Критерий: H4 / H5 / object-lifecycle. Evidence: DEVICE+CODE.

Направление: Карточка открывает обзор/материал объекта, Edit является явным действием. Сохранять Song Sheet/Lab и существующий редактор, а не создавать ещё одну копию сущности.

Код: `lib/screens/songs/songs_list_screen.dart:715-723`.

## UX-004 · S3 · Недоступные песни видны, но причины и дальнейшее действие не объяснены

В выбранном сетлисте шесть строк, четыре из них Unavailable song; строки не открываются. После Open in Metronome видна очередь из двух доступных песен. Шесть сохранённых элементов и две playable песни — разные корректные счётчики, а не доказанная арифметическая ошибка. Не установлено, почему ссылки не разрешились: удаление, загрузка или права.

Критерий: H1 / H9 / ST-recovery. Evidence: DEVICE+CODE.

Направление: До перехода показать playable/недоступно, предоставить безопасную диагностику и подходящий retry, если он применим. Не удалять и не перепривязывать ссылки автоматически; не раскрывать данные, запрещённые правами.

Код: `lib/widgets/setlist_song_row.dart:11-16`, `lib/widgets/setlist_song_row.dart:37-39`, `lib/widgets/setlist_song_row.dart:49-65`, `lib/widgets/metronome/song_library_block.dart:170-182`.

## UX-005 · S2 · Нет видимого единого входа для продолжения конкретного рабочего контекста

В осмотренных состояниях статистика, материалы, задачи и транспорт разнесены; карточки «продолжить: песня · источник · партия · фрагмент · темп» не обнаружено. Это не утверждение, что отсутствует всякое сохранение состояния. Частота и стоимость реальной потери контекста требуют human task test; прежняя недельная статистика не доказывает повторения Stop→Play.

Критерий: H6 / IA-context / task-continuity. Evidence: DEVICE; HYPOTHESIS about user impact.

Направление: Один context summary и явный Resume без автозапуска звука. Сначала проверить реально сохраняемые поля; не рисовать недостоверный фрагмент и не создавать новую параллельную модель песни.

Код: `docs/plans/unified-workspace/PROPOSAL.md`.

## UX-006 · S3 · При активном MIDI исчезает общий вход выбора сопровождения

Без активного MIDI есть Backing tracks; с активным MIDI показан LaunchpadView, а прежняя кнопка отсутствует. Меню MIDI в этом состоянии содержит Edit arrangement / Add MIDI file / Hide MIDI. Код подтверждает взаимоисключающие ветви. Это потеря конкретного общего входа, не доказательство полной недоступности Drums всеми возможными маршрутами.

Критерий: H3 / H4 / progressive-disclosure. Evidence: DEVICE+CODE.

Направление: Оставить постоянный Source/Backing selector при любом представлении. Выбор партии, редактирование, скрытие панели и замена материала — отдельные действия; не требовать Hide MIDI ради смены рабочего инструмента.

Код: `lib/screens/metronome_screen.dart:588-609`, `lib/screens/metronome_screen.dart:617-654`, `lib/widgets/metronome/backing_sheet.dart:45-76`.

## UX-007 · S2 · У кнопки создания песни отсутствует явное имя в текущей иерархии

Оранжевая FAB видна как плюс, но в захваченной UIAutomator-иерархии кнопка без имени. В вызов SingleFab не передан tooltip, параметр по умолчанию null. Это подтверждает конкретный пробел имени, но не заменяет полноценный TalkBack-тест.

Критерий: A11Y-name / H6. Evidence: DEVICE+CODE.

Направление: Передать существующему SingleFab tooltip/semantic label «Add song»; проверить остальные create FAB. Новый компонент и новый пакет не нужны.

Код: `lib/screens/songs/songs_list_screen.dart:643-648`, `lib/widgets/fab_variants.dart:20-25`, `lib/widgets/fab_variants.dart:42-49`.

## UX-008 · S1 · Микротекст вне общей шкалы требует отдельной проверки читаемости

Подписи иконки tune/fine-tune в transport_bar имеют fontSize 7 и 9. Это локальное расхождение с основной типографической шкалой, не измеренная потеря читаемости на всех устройствах и не самостоятельное численное нарушение WCAG.

Критерий: DS-type / VD-readability. Evidence: CODE.

Направление: Проверить этот компактный режим при увеличенном шрифте; использовать существующую caption/label-роль либо достаточную подпись/tooltip. Не увеличивать всю музыкальную нотацию и все метаданные одной глобальной заменой.

Код: `lib/widgets/tuner/transport_bar.dart:288-322`.

## UX-009 · S2 · Загрузка и ошибка в Practice могут выглядеть как отсутствие пользовательских данных

Practice читает несколько AsyncValue через asData?.value с fallback на пустые stats/lists. При отсутствии asData экран выбирает те же ветви, что для реального пустого журнала/домашних заданий. Ошибка сети на устройстве намеренно не провоцировалась. В Songs уже есть отдельные loading/error/cached-data состояния: lib/screens/songs/songs_list_screen.dart:654-739.

Критерий: H1 / ST-loading / ST-error. Evidence: CODE.

Направление: Переиспользовать существующие состояния loading/error/retry/cached-data; отличать «ещё загружаем» и «не смогли загрузить» от настоящего empty. Не добавлять отдельную инфраструктуру состояний.

Код: `lib/screens/practice_screen.dart:23-30`, `lib/screens/practice_screen.dart:46-50`, `lib/screens/practice_screen.dart:80-85`.
