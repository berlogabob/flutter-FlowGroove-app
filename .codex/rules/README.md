# Rules

This folder holds the policy layer that was previously spread across the legacy `.qwen/agents/README.md`, `.qwen/agents/sequential-workflow.md`, `.qwen/agents/PROTECTED_FILES_RULE.md`, and rule-heavy sections of the archived `QWEN.md`.

## Files

- `protected-files.md` — copied from the Qwen protected-files rule and path-normalized where needed.
- `sequential-workflow.md` — copied from the Qwen sequential workflow protocol.
- `operating-rules.md` — normalized summary of the active project rules and how to interpret the migrated material.

## Interpretation

- `protected-files.md` is the hard safety rule.
- `sequential-workflow.md` is historical process guidance from the Qwen setup.
- `operating-rules.md` is the quick-reference entry point for the migrated Codex structure.
